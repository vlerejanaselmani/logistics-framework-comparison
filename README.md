# Logistics Framework Comparison

A full-stack logistics CRUD system implemented using multiple backend and frontend frameworks.

## Purpose

This project is designed to compare how the same logistics requirements are implemented using different technologies while keeping the system’s functionality and API contract consistent.

## Planned Technologies

### Backends

- Spring Boot
- ASP.NET Core
- Express
- Laravel

### Frontends

- React
- Angular
- Vue

## Core Logistics Features

The system will support:

- Managing shipments
- Managing customers
- Managing drivers
- Managing vehicles
- Assigning drivers and vehicles to shipments
- Tracking shipment status

## Project Structure

- `backends/` — backend implementations
- `frontends/` — frontend implementations
- `docs/` — shared requirements, API contract, and database design

## Current Status

Project structure initialized. Requirements and system design are in progress.
